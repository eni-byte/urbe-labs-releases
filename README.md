# URBE LABS — téléchargements

Ce dépôt contient uniquement les paquets binaires signés que l'application **URBE LABS HUB** télécharge et installe. Il ne contient aucun code source.

- Chaque paquet est accompagné d'un manifeste signé (Ed25519) : le HUB vérifie la signature et la somme SHA-256 de chaque fichier avant toute installation.
- Les plugins demandent une licence URBE LABS : sans licence, le son traverse le plugin sans traitement.
- Installez les plugins depuis le HUB, pas à la main.
